# Documentation

Start with these four guides. Detailed contracts stay with the components they describe.

| Guide | Use it to |
|---|---|
| [Getting started](developer-guide.md) | Configure a macOS host and build your first window |
| [Examples and components](examples.md) | Run Fieldnotes, watch app workflows and choose controls |
| [Glass and platform behaviour](liquid-glass.md) | Choose native toolbars or floating glass and handle fallbacks |
| [Support](support.md) | Check environment coverage, limitations and remaining acceptance |

For existing apps, read [Migration](migration.md). For task composition, read
[Recipes](composition-recipes.md). The [selected API dictionary](../skills/flutter-macos-golden-gate/references/api-v1.md)
and optional [consumer skill](../skills/flutter-macos-golden-gate/SKILL.md) support integration.

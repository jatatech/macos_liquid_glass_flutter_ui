# Changelog

## 0.9.0-dev.1 — 2026-11-08

Initial public pre-release of this fork, retaining the `macos_ui` import and
upstream MIT provenance. Available from Git; not published to pub.dev.

- Semantic themes, live accessibility adaptation and readable opaque content.
- Hierarchical sidebar, toolbar overflow and keyboard/interaction repairs across
  buttons, value controls, fields/search, selectors, lists, tabs and transients.
- Actual native Liquid Glass command/navigation surfaces over Flutter content,
  shared `MacosGlassSurface`, focus/overlay/lifecycle handling, portable Flutter
  approximation and opaque accessibility/compatibility fallbacks.
- Flat text table and document inspection/session Save/Revert examples.
- Bounded native update scheduling with latest-state coalescing and ordered disposal.
- Public consumer examples, API/migration guides and optional integration skill.

Capacity/rating preserve continuous duplicate/fractional pointer proposals.
Native hosting is bounded and single-window. Full user/environment acceptance,
minimum/current SDK verification and controlled profiling remain open; see
[support and known limitations](docs/support.md).
